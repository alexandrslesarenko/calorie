# Calorie

Android-приложение для подсчёта калорий с упором на похудение. Распознаёт еду на фото и
в описании словами через Claude Haiku 5.5 или Gemini 3.5 Flash-Lite, находит продукты по
штрихкоду в Open Food Facts, ведёт дневник питания и журнал веса, считает суточную норму
под цель.

Версия 0.2, приложение на стадии испытаний, название рабочее. Готовый APK - на странице
[Releases](https://github.com/alexandrslesarenko/calorie/releases). Чтобы получать
обновления автоматически, добавьте адрес репозитория
`https://github.com/alexandrslesarenko/calorie` в
[Obtainium](https://github.com/ImranR98/Obtainium): он следит за страницей Releases и ставит
новые версии поверх старых.

## Возможности

- Еда по фото (камера или галерея), по описанию словами, по штрихкоду или вручную.
  Распознанное можно поправить перед сохранением: названия, граммы, приём пищи.
- "Мои блюда": каждое сохранённое блюдо запоминается, повтор идёт без запроса к Claude.
  Ответы тоже кешируются, так что повторная отправка того же фото или текста бесплатна.
  Продукт можно подготовить заранее, не съедая (например, по фото этикетки), потом
  поправить; в списке видна маленькая картинка.
- Значения с этикетки для сухих макарон или крупы, а взвешиваете готовое: отметка "Вес после
  готовки" и сколько весят готовыми 100 г - значения пересчитаются. Число подставляется
  само: ваше с прошлого раза или обычное для макарон, риса, круп, бобовых, мяса и рыбы (по
  категории Open Food Facts или по названию). Если значения похожи на уже пересчитанные,
  приложение предупредит, чтобы не пересчитать дважды.
- Штрихкод хранится вместе с блюдом: товар, которого нет в Open Food Facts, при следующем
  скане найдётся в "Моих блюдах", даже без сети.
- Если Claude перегружен или нет связи, запрос не пропадает: приложение само отправит его
  ещё раз и покажет ответ на "Сегодня" - останется проверить и добавить.
- Дневник по приёмам пищи, баланс каждого дня к норме, которая была в тот день (изменение
  веса или активности потом прошлое не пересчитывает), дефицит или избыток за последнюю
  неделю в килограммах жира.
- Журнал веса с графиком; под ним - съеденное накануне к норме дня, чтобы видеть, как питание
  сказывается на весе.
- Резервная копия в файл и обратно: дневник, журнал веса, нормы по дням, "Мои блюда" с картинками и профиль в JSON -
  их можно добавить к данным на другом телефоне или заменить ими всё; дневник в CSV для таблиц.
- Суточная норма по формуле Миффлина-Сан Жеора, уровню активности и выбранному темпу,
  с ограничениями безопасности: не ниже 1200 / 1500 ккал и основного обмена, не больше
  1% веса в неделю, поддержание при достигнутой цели или ИМТ ниже 18.5.
- Активность из [Pulsar](https://github.com/alexandrslesarenko/pulsar) по желанию: пульс
  на прогулках и тренировках может понизить уровень активности из профиля, но не поднять -
  прогулки сверх него норму не повышают, сожжённое на них ускоряет похудение.
- Расход по тренду веса: после двух недель полного дневника и регулярных взвешиваний
  приложение измеряет, сколько вы на самом деле тратите (съеденное плюс ушедшее с весом), и
  берёт это раньше Pulsar и ручного уровня, но только чтобы понизить норму, а не поднять;
  на странице цели он виден рядом с расчётом по формуле.
- Интерфейс на 9 языках: английский, русский, немецкий, французский, испанский,
  итальянский, японский, корейский, китайский (упрощённый). Claude отвечает на языке
  приложения.

## Ключ API: Claude или Gemini

Для распознавания по фото и описанию нужен свой ключ API; достаточно любого из двух
сервисов.

- Claude: ключ с [platform.claude.com](https://platform.claude.com). Оплата по факту
  использования, отдельно от подписок Claude: около 0.05 цента за фото на Claude Haiku 5.5.
- Gemini: ключ из [Google AI Studio](https://aistudio.google.com/apikey). Бесплатный тариф
  ничего не стоит, но на нём Google может использовать отправленное для улучшения своих
  продуктов; на платном - нет.

Расход каждого сервиса приложение считает само по числу токенов в ответах. Штрихкоды,
дневник, "Мои блюда" и ответы из кеша работают без ключа.

Ключи зашифрованы ключом из Android Keystore и исключены из облачной копии.

### Выбор распознавателя

Настройки - "Распознавание": Claude Haiku 5.5 (по умолчанию) или Gemini 3.5
Flash-Lite. Если выбранную модель сняли с обслуживания, ответит следующая, у которой
есть ключ, и экран подтверждения об этом скажет. Перегруженный сервис приложение ждёт в
очереди повторов, а после третьего отказа подряд отвечает следующая модель с ключом.

## Конфиденциальность

- Фото и описания отправляются в Claude API, а в Gemini API - если он выбран или
  ответил как запасной (на бесплатном тарифе Google может их использовать). Перед
  отправкой фото пересохраняется, поэтому данные EXIF и геометка не покидают телефон.
- Штрихкоды отправляются в Open Food Facts (без аккаунта и ключа).
- Дневник, журнал веса и профиль остаются на телефоне.

## Требования

- Android 12 (API 31) или новее.
- Сервисы Google Play для сканера штрихкодов.
- Ключ Claude API или Gemini API для распознавания фото и текста.

## Сборка

Нужны JDK 17 и Android SDK. Путь к SDK - в `local.properties` (`sdk.dir=...`) или в
переменной `ANDROID_HOME`.

```bash
./gradlew :app:assembleDebug         # APK в app/build/outputs/apk/debug/
./gradlew :app:installDebug          # поставить на подключённый телефон
./gradlew :app:assembleRelease       # APK в app/build/outputs/apk/release/
./gradlew :app:testDebugUnitTest     # unit-тесты, без устройства и без запросов к API
```

## Связь с Pulsar

Calorie читает поминутный пульс на прогулках и тренировках из content provider'а Pulsar.
Доступ закрыт signature-разрешением, поэтому оба приложения должны быть подписаны одним
ключом. Авторские сборки обоих приложений подписаны общим release-ключом. Сборки из
исходников на одной машине подписаны её debug-ключом, так что собранная самостоятельно
пара работает сразу, но самостоятельно собранный Calorie не прочитает Pulsar, поставленный
со страницы Releases. Если Calorie поставлен раньше Pulsar, Calorie нужно переустановить,
чтобы получить разрешение.
